## 1. バックエンド

| カテゴリ | 技術 | バージョン方針 | 状態 |
|----------|------|----------------|------|
| 言語 | C# | .NET の LTS に対応する版 | 採用 |
| フレームワーク | ASP.NET Core Web API | 最新 LTS（.NET） | 採用 |
| ビルド・実行 | `dotnet` CLI（SDK） | .NET の最新 LTS | 採用 |
| DB | MySQL | 8.4 LTS 系を想定（**要確認**） | 採用 |
| ORM | Entity Framework Core | **9.0.21**（`dotnet-ef` も同じ版）。EF Core 10 に対応する Pomelo が未リリースのため、.NET 10 上で EF Core 9 を使う | 採用（動作確認済み） |
| MySQL プロバイダ | Pomelo.EntityFrameworkCore.MySql | **9.0.0**（EF Core 9 対応の最新） | 採用（動作確認済み） |
| マイグレーション | EF Core Migrations | – | 採用（[04.データモデル.md §6](04.データモデル.md)） |
| バリデーション | DataAnnotations（必要なら FluentValidation） | – | 採用 / 候補 |
| JSON | System.Text.Json（camelCase） | – | 採用 |
| 単体テスト | xUnit | 2.9.3（`Domain` はフレームワーク非依存でテスト） | 採用 |
| 結合テスト（API） | `WebApplicationFactory` + Testcontainers for .NET（`mysql:8.4` を実行ごとに起動） | Testcontainers.MySql 4.16.0。Docker が必要 | 採用 |
| アーキテクチャ検査 | NetArchTest | – | 候補（レイヤ依存・`double` 禁止の機械検証） |

- EF Core を 9 系に固定している理由: Pomelo が EF Core 10 に未対応のため。Pomelo が EF Core 10 に対応したら、EF Core・`dotnet-ef`・Pomelo をそろえて上げる（その際はマイグレーションが変わらないことを API テストで確認する）。
- 栄養計算は `decimal`（丸めは `MidpointRounding.AwayFromZero` = HALF_UP）のみ（NFR-001）。`double`/`float` を計算に使わない。
- API 文書は本リポジトリの [09.API仕様.md](09.API仕様.md) が正本。Swagger/OpenAPI の自動生成は導入しない（二重管理を避ける。要すれば候補として再検討）。
- DB の日本語名（テーブル `T`＋日本語名、列は日本語）は EF Core の Fluent API でマッピングする（[ADR-0007](adr/0007-DB物理名を日本語にする.md)）。

|----------|------|----------------|------|
| フレームワーク | Angular（standalone コンポーネント・signals） | 22 系（プロトタイプ導入時の最新安定版） | 採用 |
| 言語 | TypeScript | Angular が要求する版（6 系。`strict`） | 採用 |
| ビルド・CLI | Angular CLI | Angular と同じ版 | 採用 |

| スタイル | Tailwind CSS | 4 系（`@tailwindcss/postcss`）。グラスモーフィズムのデザイントークンは `src/styles.css` | 採用（プロトタイプで導入） |
| グラフ | **ライブラリなし**（自前の SVG: スコアのリング・kcal の棒・スコアの折れ線） | – | 採用（線種・マーカーで系列を区別でき、依存が増えない。複雑になれば ng2-charts 等を再検討） |
| 単体テスト | Angular CLI 標準のテストランナー（`ng test`。Vitest + jsdom） | Vitest 5 系 | 採用（Angular Testing Library は必要になったら追加） |

| Lint | angular-eslint（`@typescript-eslint/no-explicit-any` を有効化） | – | 候補 |

- `any` 禁止（TypeScript `strict` + Lint ルール）。型は `src/app/types` に集約（[12.アーキテクチャ.md](12.アーキテクチャ.md)）。
- 状態を色だけで表現しない（NFR-004）。グラフ系ライブラリ選定時は、線種・マーカー・ラベルで区別できるかを基準に含める。

## 4. ポート（各ツールの標準に合わせる）

| サービス | ポート | 備考 |
|----------|--------|------|
| バックエンド（ASP.NET Core） | **8080** | `GET /health` → `{"status":"ok"}`。起動 URL を `http://localhost:8080` に固定する（既定の 5000 番台は使わない） |
| フロントエンド（Angular 開発サーバー） | **4200** | `proxy.conf.json` で `/api` を `localhost:8080` にプロキシ |
| DB（MySQL） | **3306** | Docker |

競合時は別ポートで逃げず、占有プロセスを止めて固定ポートで起動する。
