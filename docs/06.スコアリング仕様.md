## 1. 共通ルール

### 1.1 達成率

| 目標の型 | 該当 `種別` | 達成率 |
|----------|-------------|--------|
| 下限型 | `RDA` / `AI` / `DG_MIN` | `min(摂取量 ÷ 目標, 1.0)` |
| 範囲型 | `DG_MIN` + `DG_MAX` | 範囲内なら満点（1.0）。下回れば下限型と同じ。上回れば §1.2 |
| 上限型 | `DG_MAX` / `UL` | 超過時のみ警告／減点（達成率という概念は使わない） |

- 下限型の目標が複数ある栄養素は、**優先順位 `RDA` > `AI` > `DG_MIN`** で 1 つ選ぶ（暫定）。
- **100% で頭打ち**にし、過剰な栄養素で他の不足を相殺させない（[ADR-0004](adr/0004-スコアの頭打ちと7日平均.md)）。
- 達成率は小数 6 桁（HALF_UP）で保持し、スコアは最後に整数へ HALF_UP する。

### 1.2 UL・上限の扱い

- `UL` 超過は**当日値**で判定し警告する（7 日平均でも、日ごとに判定し「期間内に UL を超えた日数」を表示する。暫定）。
- 警告は文言（「上限を超えています」）とアイコンで示し、色だけにしない（NFR-004）。

### 1.3 評価期間（ADR-0004）

| 表示 | 摂取量の求め方 |
|------|----------------|
| 今日の進捗（FR-043 の「今日」） | 指定日 1 日分の合計。7 日平均とは**別表示** |
| 直近 7 日平均（評価の主軸） | 窓 = `endDate−6` 〜 `endDate`。**記録日（食事記録が 1 件以上ある日）のみ**で平均する（記録のない日は分母に含めない） |

- 窓内の記録日が **3 日未満**なら 7 日平均のスコアは出さず「データ不足」を表示する（FR-046）。
- 7 日平均の摂取量 = Σ（記録日の日合計）÷ 記録日数。

## 2. 目標値の算出（FR-002）

| 対象 | 式 | 備考 |
|------|----|------|
| エネルギー（kcal） | Mifflin-St Jeor × 活動係数、**整数に四捨五入（HALF_UP）** | ユーザー上書き（`エネルギー目標kcal`）があればそれを優先 |
| タンパク質（g） | 体重(kg) × 係数(g/kg) | 係数は目的別（暫定、Q-4） |
| その他の栄養素 | `T栄養目標` を性別・年齢で引く | **Q-2（要転記）**。数値は本書に書かない |

Mifflin-St Jeor（BMR, kcal/日）:

- 男性: `10×体重(kg) + 6.25×身長(cm) − 5×年齢 + 5`
- 女性: `10×体重(kg) + 6.25×身長(cm) − 5×年齢 − 161`

| `活動レベル` | 活動係数（暫定） |
|------------------|------------------|
| 1 | 1.2 |
| 2 | 1.375 |
| 3 | 1.55 |
| 4 | 1.725 |

| `goal` | タンパク質係数 g/kg（暫定） |
|--------|------------------------------|
| skin | 1.0 |
| both | 1.4 |
| muscle | 1.6 |

- 年齢は対象日時点の満年齢。
- `T栄養目標` の検索: `性別` が一致または `all`、かつ `年齢下限 ≤ 年齢 ≤ 年齢上限` の行。該当行が無い栄養素は「目標未設定」とし、スコア計算からは除外して重みを再正規化する（暫定）。
- 計算例（テスト用）: 男性・30 歳・身長 170cm・体重 65kg・活動レベル 2 → BMR = 650 + 1062.5 − 150 + 5 = 1567.5、× 1.375 = 2155.3125 → **2155 kcal**（AC-SCORE-007）。

## 3. 美肌スコア（`beautyScore`）

達成率の**加重平均 × 100**。

| 栄養素 | code | 重み（暫定） |
|--------|------|--------------|
| ビタミン C | `VITC` | 1 |
| ビタミン E（α-トコフェロール） | `VITE_ATOC` | 1 |
| ビタミン A（レチノール活性当量） | `VITA_RAE` | 1 |
| 亜鉛 | `ZN` | 0.5 |

```
beauty = Σ(重み × 達成率) ÷ Σ重み × 100       → 整数に HALF_UP
```

- アスタキサンチン（`ASTX`）は**参考表示のみでスコア外**（Q-3）。

## 4. 筋肉スコア（`muscleScore`）

```
muscle = 0.6 × タンパク質達成率 + 0.2 × 分配率 + 0.2 × エネルギー充足   （× 100、整数に HALF_UP）
```

| 要素 | 定義 |
|------|------|
| タンパク質達成率 | `min(摂取量 ÷ 目標, 1.0)`。目標 = 体重 × 係数（§2） |
| 分配率 | **朝・昼・夕のうち、その食事のタンパク質が 20g 以上だった食事の割合**。間食（snack）は分母に含めない。同じ日・同じ区分の記録は 1 食として合算する。窓内の朝昼夕の食事数に対する割合（暫定） |
| エネルギー充足 | `d = abs(摂取/目標 − 1)`。`d ≤ 0.10` なら 1。超えたら `max(0, 1 − (d − 0.10) ÷ 0.40)` |

- 朝昼夕の記録が 1 件も無い場合、分配率を除外し、残りの重み（0.6, 0.2）を再正規化する（0.75 / 0.25）。
- 閾値 20g、許容幅 0.10 / 0.40 は**暫定**（Q-4）。
- PFC 比は情報表示のみでスコア外。

## 5. 基礎スコア（`baseScore`）

```
base = ( Σ達成率 ÷ 11 × 100 ) − 食塩減点     （下限 0、整数に HALF_UP）
```

対象 11 栄養素（各重み 1）: `FIBTG`, `CA`, `FE`, `MG`, `K`, `VITB1`, `VITB2`, `VITB6`, `VITB12`, `FOL`, `VITD`。

食塩（`NACL_EQ`）は目標上限（`DG_MAX`）を超えた場合のみ減点:

```
食塩減点 = min(10, 20 × (摂取量 ÷ 上限 − 1))      （超過時のみ。超過なしは 0）
```

## 6. 正解データ（単日・テスト用の仮目標）

> **目標値はテスト用の仮の値で、食事摂取基準の公式値ではない**。[10.受け入れ基準.md](10.受け入れ基準.md) の AC-SCORE-001/002 と一致させている。

### 6.1 美肌

| 栄養素 | 摂取量 | 目標（仮） | 達成率 | 重み | 重み×達成率 |
|--------|--------|------------|--------|------|--------------|
| VITC | 78 | 100 | 0.780000 | 1 | 0.780000 |
| VITE_ATOC | 9 | 6 | 1.000000（頭打ち） | 1 | 1.000000 |
| VITA_RAE | 450 | 700 | 0.642857 | 1 | 0.642857 |
| ZN | 8 | 10 | 0.800000 | 0.5 | 0.400000 |

`(0.78 + 1 + 0.642857 + 0.4) ÷ 3.5 = 0.806531` → ×100 = 80.65 → **81**

### 6.2 筋肉

| 要素 | 入力 | 値 |
|------|------|----|
| タンパク質達成率 | 目標 = 60kg × 1.5 = 90g（仮係数）、摂取 62g | 62 ÷ 90 = 0.688889 |
| 分配率 | 朝 25g / 昼 22g / 夕 15g（≥20g は朝・昼の 2 食） | 2 ÷ 3 = 0.666667 |
| エネルギー充足 | 摂取 1800 / 目標 2000 = 0.9（d = 0.10 ≤ 0.10） | 1.000000 |

`0.6×0.688889 + 0.2×0.666667 + 0.2×1.0 = 0.413333 + 0.133333 + 0.2 = 0.746667` → ×100 = 74.67 → **75**

### 6.3 基礎（食塩減点の例）

| 入力 | 値 |
|------|----|
| 11 栄養素の達成率 | すべて 0.8 → 平均 80 |
| 食塩（仮上限 7.0g、摂取 8.4g） | 減点 = min(10, 20 × (8.4/7.0 − 1)) = min(10, 4.0) = 4.0 |
| 基礎スコア | 80 − 4 = 76 → **76** |

### 6.4 エネルギー充足の境界

| 摂取/目標 | d | 充足 |
|-----------|---|------|
| 0.90 / 1.10 | 0.10 | 1.0 |
| 0.70 / 1.30 | 0.30 | 1 − (0.30−0.10)/0.40 = 0.5 |
| 0.50 / 1.50 | 0.50 | max(0, 1 − 0.40/0.40) = 0 |

## 7. 表示

| 項目 | 仕様 |
|------|------|
| スコア値 | 整数（四捨五入） |
| 帯 | **≥ 80: 良好 / 60–79: もう少し / < 60: 不足気味**（文言は責めない。色だけでなく文言・アイコンを併記） |
| データ不足 | 7 日平均で記録日 < 3 日: 「データ不足（記録 n 日）」。スコアは出さない |
| 欠測 | 栄養素に `不完全フラグ` がある場合、そのスコアに「※未測定の食材を含むため低めに出ている可能性」を注記（FR-046） |
| 免責 | 「食事摂取基準に基づく目安であり、医療的助言ではありません」を必須表示（FR-047） |
