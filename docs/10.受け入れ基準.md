## 1. 方針

### 1.1 ID と形式

- ID は `AC-<領域>-<番号>`。領域: `CALC`（栄養計算）/ `SCORE`（スコア・目標）/ `PROF`（プロフィール）/ `FOOD`（食材）/ `MENU`（メニュー）/ `REC`（記録）/ `DASH`（サマリ・ダッシュボード）/ `NFR`（非機能）。
- 欠番は詰めない。廃止する場合は「廃止」と明記して残す。
- 記述は Given / When / Then。数値の厳密な基準は §3・§4 の表。

### 1.2 テスト層

| 層 | 略称 | 対象 | 技術（[11.技術スタック.md](11.技術スタック.md)） |
|----|------|------|-----------------------------------------|
| 単体（バックエンド） | U | `domain` の純粋関数（栄養計算・スコア・目標算出）。**ASP.NET Core を起動しない**（`Domain` プロジェクトのテスト） | xUnit（候補） |
| API | A | Controller〜DB。実 DB でバリデーション・スナップショット・集計を検証 | ASP.NET Core の `WebApplicationFactory` + Testcontainers for .NET（MySQL）（候補） |
| 単体（フロント） | F | 表示整形・状態表現（色以外の併記）・フォーム検証 | Angular CLI 標準のテストランナー + Angular Testing Library（候補） |
| E2E | E | 主要シナリオ（S-1〜S-5）を 375px 幅で通す | Playwright（候補） |

- **正解データ（§3・§4）は U 層で網羅**し、A 層で代表ケース（AC-CALC-004・006）を DB 経由で再確認する。
- 浮動小数点は使わない。`decimal` を使い、比較は `Assert.Equal(期待値m, 実測値)`。`decimal` の等値比較はスケールを無視する（`0.1875m == 0.187500m`）。桁数（保存値は `DECIMAL(14,4)` なので 4 桁）を確認したい場合は丸め関数の戻り値に対して別途検証する。
- テスト名に AC の ID を含める（例: `AC_CALC_006_oneAndHalfServing`）。ID のテスト漏れは grep で機械確認できる形にする（実装時にスクリプト化。候補）。

### 1.3 正解データの置き場（候補）

正解データは JSON/CSV 化し `backend/tests/` 配下の `Golden/` フォルダ（暫定）に置いて U・A 層で共有する。数値の正本は本書と [03.栄養計算仕様.md §9](03.栄養計算仕様.md)・[06.スコアリング仕様.md §6](06.スコアリング仕様.md)。**3 文書の数値が一致していること**を保つ（変更時は 3 か所を同時に更新）。

## 3. 栄養計算の正解データ（AC-CALC）

> **テスト用ダミー値であり、実際の成分表の値ではない。** 食材・メニューの定義は [03.栄養計算仕様.md §9.1〜9.2](03.栄養計算仕様.md)。以降、`PROT`=g、`VITC`=mg、`VITA`=`VITA_RAE`(μg)。

前提データ:

| 食材 | 廃棄率 | PROT/100g | VITC/100g | VITA/100g | 単位 |
|------|--------|-----------|-----------|-----------|------|
| F1 にんじん | 10.0 | 1.0 | 10 | 700 | 1 本=150g |
| F2 豚こま肉 | 0 | 20.0 | 1 | 10 | – |
| F3 みそ | 0 | 12.0 | NULL | 0 | 大さじ=18g |

### 3.4 テストコード化の例（参考）

```csharp
// AC_CALC_006: 1.5杯 → PROT は 17.12625 を HALF_UP して 17.1263
[Fact]
public void AC_CALC_006_OneAndHalfServing()
{
    decimal ratio = PortionCalculator.Ratio(InputMode.Serving, 1.5m,
        cookedTotalWeightG: 2400.0m, servings: 8.0m);
    Assert.Equal(0.187500m, ratio);   // decimal の等値比較はスケールを無視する

    NutrientAmount prot = SnapshotCalculator.Snapshot(menuTotal, ratio)["PROT"];
    Assert.Equal(17.1263m, prot.Amount);
}
```
