# マスタ CSV の置き場

起動時（`Nutrition:MasterImport:Enabled` が true のとき）に、このフォルダの CSV を DB へ取り込みます。仕様は [docs/07.マスタデータ仕様.md](../../../../docs/07.マスタデータ仕様.md) が正本です。

| ファイル | 取り込み先 | 必須 |
|----------|-----------|------|
| `食材.csv` | `T食材` | 食材を取り込むとき |
| `食材栄養素.csv` | `T食材栄養素` | – |
| `食材単位.csv` | `T食材単位` | – |
| `食材別名.csv` | `T食材別名` | – |
| `栄養目標.csv` | `T栄養目標` | – |

- ファイルが 1 つも無ければ何もしません（スキップ）。
- 食品コード等をキーに upsert するので、何度実行しても結果は同じです。CSV から消した食材は、削除せず無効になります。
- 検証エラーが 1 件でもあれば、行番号つきで報告して**何も取り込まず、アプリは起動しません**。
- **CSV は `.gitignore` で除外しています。** 成分表の利用条件（Q-1）と食事摂取基準の転記（Q-2）が確認できるまで、実データはコミットしません。ダミーの例はテスト（`tests/NutritionTracker.Api.Tests/MasterImport/MasterImportTests.cs`）にあります。
