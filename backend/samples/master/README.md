# 動作確認用のダミーのマスタ CSV

画面・API の動作確認と E2E テストのための、**ダミーのデータ**です。食材 23 品の栄養値と、栄養目標（16 件）は、動作確認のために作った値で、**日本食品標準成分表や食事摂取基準の公式の値ではありません**（出典版は「動作確認用ダミー」）。にんじん・豚こま肉・みそは、設計書の正解データ（[docs/03.栄養計算仕様.md](../../../docs/03.栄養計算仕様.md) §9）と同じ値です。

使い方（バックエンドを起動する前に、`Master/` へコピーする。コピー先の CSV は `.gitignore` で除外されている）:

```bash
cp backend/samples/master/*.csv backend/src/NutritionTracker.Api/Master/
```

バックエンドの起動時に取り込まれます（食品コードで追加・更新するので、何度でも同じ結果）→ [Master/README.md](../../src/NutritionTracker.Api/Master/README.md)。実データ（成分表・食事摂取基準）は、Q-1・Q-2 の確認が済むまでコミットしません。
